# GeometricMultiFractal

Civilization IV: Beyond the Sword mapscript and browser-based helper toolkit.

## Open the Toolkit

Use the launcher page:

[Open index.html](index.html)

If GitHub Pages is enabled, use:

https://AineiasStymphalios.github.io/GeometricMultiFractal/

## Contents

- `GeometricMultiFractal.py` — Civ4 mapscript
- `index.html` — toolkit launcher and instructions
- `webapps/GMF_Plot.html` — plot/landmass tool
- `webapps/GMF_Climate.html` — climate tool
- `webapps/GMF_Rivers.html` — river tool
- `webapps/GMF_MiscRegions.html` — spawn and bonus region tool
