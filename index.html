Description

This toolkit contains the GeometricMultiFractal.py mapscript (used as a base map) and 4 webapps to support mapscript generation.

The mapscript uses a custom fractal plot generator based on the MultiFractal class used in several vanilla CivIV mapscripts. This generator allows one to generate maps with very specific geographies. Included are several other features: climate-based terrain / feature generator, custom river mapper, fixed starting locations, bonus additions to specific areas of the map.

Usage

Duplicate Geometric_MultiFractal.py and rename it.

Open index.html (this page) to launch the toolkit menu.

The webapps can be opened directly from the repository, through GitHub Pages, or offline from a downloaded copy of the repo.

Each webapp generates a list or data block. Copy the generated output into the matching function inside Geometric_MultiFractal.py.

Examples

The mapscript comes with 3 example maps, available under the Geographic Accuracy option.

  • Low: Generates simple shapes. Use to get the hang of the GMF method.
  • Medium: Generates a crude outline of China.
  • High: Generates a map of Australia and New Zealand.

1. Base Terrain

Open GMF_Plot. Load a background image as needed.

Add fractal regions to the canvas from the right panel. Supported shapes include rectangles, ellipses, and triangles.

Region Properties

Altitude
Sets the region's hill and peak frequency. Water altitude tries to fill with water tiles instead.
Grain
Sets the region's fractal grain. Graininess is Scatter > Balance > Gather.
Hills Grain
Sets the fractal grain for hills and peaks.
Water %
Sets the probability that a tile within the region will be skipped in fractal generation.

2. Climate

Open GMF_Climate.

Add linear or radial climate drivers. Switch canvas modes through the buttons in Display / Target.

Driver Properties

Target
Temperature or moisture.
Type
Linear, mirrored, or radial.
Origin XY
Start coordinate of the vector.
Start / End
Temperature or moisture values added at the origin and at the end of the vector.

3. Rivers

Open GMF_Rivers.

Add rivers and waterways. A waterway is a 1-tile-wide path of water. Click on the canvas to add points.

When a river is complete, click Deselect or press Esc.

River Properties

Meander
Controls how much the river can meander between river points.
Bridge Spacing
Attempts to add land bridges across waterways at the specified interval.

River Tips

  • Rivers stop generating once they hit a water body or cross another river.
  • Place the mouth point slightly deeper into water to avoid ending before the coast.
  • To create branching rivers, draw the branch so that it extends past the main river.

4. Spawns and Bonuses

Open GMF_MiscRegions.

Add regions for player spawn locations and extra bonus additions.

Spawn Region Properties

Group
Priority of start assignment. The map fills primary regions first.

Bonus Region Properties

Bonus Type
Name of the bonus, specified by XML.
Count
Quantity of bonuses added to the region.
Plains if forced
If checked, forced fallback placement converts the selected tile to plains.
